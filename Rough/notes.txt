## aggregation match() ##

MongoDB Aggregation
Framework
The MongoDB Aggregation Framework is a powerful tool for performing complex
data transformations and analyses directly within MongoDB databases. It is
designed to aggregate data from multiple documents and return computed results,
allowing for operations like data summarization, transformation, and complex
filtering.



Core Components and Operations:
$match: Filters the data to pass only the documents that match specified
conditions to the next pipeline stage, similar to the find method but used
within the aggregation framework.
$project: Reshapes documents by including, excluding, or adding new
fields. It can also be used to compute new values and assign them to
fields.

mongoDB aggregation pipeline ==> []
Stages ==> $match(),  $group(),  $project()

all users age > 30 ==> db.customers.aggregate([{$match: {age: {$gte: 30}}}])

all users age between 18 to 60 ==> db.customers.aggregate([{$match: {$and:[{age: {$gte: 18}}, {age: {$lte: 60}}]}}])

users first_name ==> db.customers.aggregate([{$match: {name: 'first_name'}}])

all user salary between 1000 to 5000 ==> db.customers.aggregate([{$match: {and: [{salary: {$gt: 1000}}, {salary: {$lt:5000}}]}}])
